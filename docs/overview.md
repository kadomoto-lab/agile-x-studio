# 概要

Agile-X Studio は、[Agile-X](https://www.agile-x.t.u-tokyo.ac.jp/) のゲートアレイ向けの回路を、ブラウザの中で設計・確認するためのアプリです。論理ゲートだけでなく、ベースセルのトランジスタを直接使った回路や、抵抗・容量などを含む回路もシミュレーションできます。ゲートアレイに配置・配線するのは、ゲートとベースセルの部分です。1 つの回路を 3 つの見え方で扱います。

| 見え方 | 何をするか |
|---|---|
| **ブロック図** | 部品を並べて配線する。回路の正本はここかネットリストのどちらか |
| **ネットリスト** | SPICE ネットリストをテキストで直接編集する |
| **レイアウト** | ゲートアレイに配置・配線した結果を、ベースの GDS に重ねて表示する |

右側には波形、下にはコンソールがあり、シミュレーションの結果とログが出ます。

## 仕組み

```text
ブラウザ (React + Vite)                     API サーバ (FastAPI, 127.0.0.1:8000)
┌───────────────────────────┐   /api/*    ┌──────────────────────────────────────┐
│ ブロック図 / ネットリスト   │ ──────────▶ │ /api/simulate     → ngspice (バッチ)   │
│ 波形 (uPlot)               │ ◀────────── │ /api/layout/sync  → 配置・配線・検証    │
│ レイアウト (canvas)        │ ◀────────── │ /api/layout/tile  → KLayout で PNG 描画 │
└───────────────────────────┘             └──────────────────────────────────────┘
```

- **シミュレーション**: ブラウザはネットリストを `POST /api/simulate` に送ります。サーバは一時ディレクトリで `ngspice -b` を実行し、波形を JSON で返します。点数が多いときは表示用に間引きます。
- **レイアウト**: ブラウザはネットリストを `POST /api/layout/sync` に送ります。サーバはゲートを取り出してゲートアレイに配置し、METAL5 で配線して、結果を検証します。通ったら `base.gds` と重ねた GDS を書き出します。
- **レイアウトの表示**: API サーバが KLayout の Python モジュールで GDS を PNG のタイルに描き、ブラウザはそれを並べて表示します。ブラウザに配るのは画像だけです。
- 開発時は Vite が `/api` を API サーバに中継するので、ブラウザから見ると同じオリジンです。

## ゲートアレイ

Agile-X のゲートアレイは、ベースセル `Z__GABASECELL` を **9 行 × 35 列 = 315 個** 並べたものです。ベースセル 1 つには PMOS と NMOS が 2 個ずつ入っていて、METAL5 の配線のつなぎ方で INV・NAND2・NOR2 のどれかになります。

| 部品 | 使うベースセル | 配置 |
|---|---|---|
| INV、NAND2、NOR2、`Z__GABASECELL` | 1 ゲートにつき 1 個 | ゲートアレイに配置・配線する |
| NMOS、PMOS、MOS Cap、R、C、L、電源 | なし | シミュレーションだけに使う |

1 行に収まらない回路は複数の行にまたがって配置され、行の間はベースに組み込まれたジャンパで配線します。詳しくは [レイアウト](guide/layout.md) と [ゲートアレイ](reference/gate-array.md) を参照してください。

!!! note "シミュレーションのモデルについて"
    ベースセルのトランジスタは、ネットリスト先頭のプリアンブルにある **LEVEL=1 の簡易モデル**（`NMOSMOD1` / `PMOSMOD1`）で計算します。論理動作やおおまかな遅延の確認向けで、実際のプロセスの特性を表すものではありません。

## できないこと

- 配置・配線の結果を GUI で手直しすることはできません。レイアウトは常にネットリストから作り直します。
- DRC・LVS の本格的な検証はしません。配線の検証は、出力した METAL5 図形のショート・オープン・間隔の確認に限られます。
- API サーバに認証はありません。サーバは自分のマシンか、信頼できるネットワークの中だけで動かしてください。
