# 表示言語

画面は日本語と英語に対応しています。日本語が正本で、英語はその翻訳です。

## 切り替える

ヘッダ右上の **日本語 / English** を押すと、その場で表示が切り替わります。選んだ言語はブラウザに保存され、次に開いたときもその言語で表示されます。

- すでにコンソールに出ている行は、出したときの言語のままです。
- 部品名（Resistor、INV など）、SPICE、ネットリスト、GDS のファイル名は、どちらの言語でも英語のままです。

## 最初に表示する言語

保存された選択がないときは、起動・ビルドのしかたで決まります。

| コマンド | 最初の言語 |
|---|---|
| `npm run dev` / `npm run build` | 日本語 |
| `npm run dev:en` / `npm run build:en` | 英語 |

どちらのビルドにも両方の言語が入っているので、あとから切り替えられます。環境変数で指定するときは `VITE_LOCALE=ja` または `VITE_LOCALE=en` を使います。
